{# Custom title bar for the frameless native window. The bar stays hidden in a normal browser and is revealed only once pywebview has injected its JavaScript bridge, so developer runs (``uv run dev``) and the headless smoke test keep the normal page. The ``.pywebview-drag-region`` element is what pywebview uses to drag a frameless window. On Windows and Linux this bar draws the window controls. On macOS the native AppKit traffic lights are restored (see desktop_macos.py), so here the bar is only a transparent drag strip and the control buttons are hidden. #}
