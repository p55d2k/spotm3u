{# In-app update notice. Fetches /update/check on every page and reveals the banner only when a newer SpotM3U release is available. In the desktop shell the download is handed to the WindowControls bridge so it lands in Downloads without a native save panel; in a plain browser the asset URL opens in a new tab. After a successful download the banner clears itself (and stays dismissed for that version) and a toast tells the user to quit the app and open the downloaded installer. #}
