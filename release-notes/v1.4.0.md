SpotM3U now uses a complete native-style React desktop interface while keeping
the same playlist conversion workflow across macOS, Windows, and Linux.

## What's new

- **Complete React desktop interface.** Import, playlist selection, conversion
  progress, and results now use one consistent application UI instead of
  server-rendered pages.
- **Native desktop shell.** The application includes a frameless window,
  platform-appropriate title-bar behavior, sidebar workflow navigation, theme
  controls, and persistent WebView storage.
- **Improved import and playlist selection.** Exportify ZIP import, drag and
  drop, playlist search, single-playlist conversion, and batch conversion are
  available in the new interface.
- **Integrated progress and results.** Conversion progress, track status,
  artwork, lyrics, missing files, playlist saving, and media-player actions are
  presented in the React workflow.
- **Fast mode.** Single-playlist and batch conversion screens provide a shared
  fast-mode option for quicker downloads without source checks, audio checks, or
  metadata enrichment.

## Bug Fixes

- Fixed media-player requests for unfinished playlists so they report that the
  playlist is not ready before checking platform availability.
- Fixed a blank white window in embedded desktop WebViews when browser storage
  or system theme detection is unavailable during startup.
- Fixed selected playlist cards losing their accent border while hovered.
- Fixed sidebar footer icon alignment between the update action and theme
  toggle.

## Improvements

- Reduced unnecessary card containers, rounded surfaces, and visual clutter for
  a denser desktop-application layout.
- Added clear numbered instructions for exporting playlists from Exportify.
- Updated development and packaging workflows so `uv run dev` starts the
  complete development environment and `uv run build` builds and bundles the
  React frontend automatically.
- Updated packaged-app verification to check the React entry point, its assets,
  and the API workflow.
